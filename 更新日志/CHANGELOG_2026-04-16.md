# Chatroom 更新日志 (2026-04-16)

本文档记录了 2026 年 4 月 16 日对 Chatroom 项目进行的一系列全面重构、功能新增与对抗式 Bug 修复。

## 🚀 新增功能 (Features)

### 1. DeepSeek AI 助手接入 (#16)
- **无缝唤醒**：在聊天室中发送包含 `@AI` 的消息即可召唤助手。
- **上下文感知**：AI 自动读取最近的聊天记录作为上下文，了解当前语境。
- **多模态支持**：支持识别上下文中的图片消息（通过 DeepSeek Vision 能力）。
- **流式响应**：AI 回复采用流式输出，带有专属紫色渐变气泡、跳动思考动画与闪烁光标。
- **定向回复 (#20)**：AI 回复自动绑定触发者，形成 1对1 对话线程，并在气泡中显示 `@触发者` 标签。
- **回复触发 (#19)**：除了主动 `@AI`，用户直接回复 AI 的历史消息也能触发 AI 响应，保持对话连续性。

### 2. 输入框 @ 提及功能 (#17)
- **智能面板**：输入 `@` 或点击 `@` 按钮立即弹出包含“AI 助手”、自己及其他在线用户的列表。
- **自动补全**：支持输入字符进行模糊匹配过滤。
- **快捷交互**：支持键盘 `↑` `↓` 键选择，`Enter` 或 `Tab` 键确认，`Esc` 键关闭面板。

## 🛠️ 架构重构 (Refactoring)

- **组件拆分**：将原本长达 1200 行的 `App.tsx` 拆分为多个职责单一的子组件，包括 `LoginView`、`ChatHeader`、`MessageList`、`InputBar`、`Modals` 和 `FocusOverlay`，大幅提升代码可读性与可维护性。
- **移动端布局重构 (#18)**：彻底抛弃 `height: 100%` 链路，改用 `100dvh` + `visualViewport` 动态高度双重保障方案，彻底解决 iOS/Android 键盘弹出及收起后上滑时输入框消失或布局错位的问题。

## 🐞 核心 Bug 修复 (Bug Fixes)

### 交互与体验 (UX)
- **长按菜单规则重构**：解除 AI 消息的长按屏蔽，所有消息均可回复、复制、关闭；撤回按钮仅对自己发送的非撤回消息显示。
- **文本编辑滚动冲突 (#21)**：修复在输入框内编辑长文本时，手指上下滑动触发外层聊天列表滚动的问题。通过 CSS `overflow-y: auto` 与 JS 拦截 `touchmove` 冒泡双管齐下解决。
- **截图误触长按遮罩 (#24)**：修复系统截图手势（如音量下+电源键）误触消息长按遮罩的问题。引入移动阈值检测（>8px 取消）、多点触控取消及页面失焦（`visibilitychange`）取消三重防护。
- **自动滚动优化**：修复只要有新消息就强制滚动到底部的问题，改为仅当用户停留在底部附近（120px 内）时才自动滚动。
- **输入框 UI 优化**：删除废弃的表情系统按钮及面板，拉长输入框；移除 placeholder 中多余的引导文字；删除加号菜单中重复的“日志”入口 (#23)。

### 逻辑与稳定性 (Logic & Stability)
- **AI 重复回复 (#22)**：修复重进房间时历史消息被误认为新消息导致 AI 重复回复的问题。引入 `localStorage` 持久化已处理消息 ID 集合进行去重。
- **幽灵在线双重保障**：
  - **心跳超时剔除**：本地增加 10 秒定时器，自动剔除超过 60 秒未更新心跳的在线用户。
  - **MQTT 遗嘱消息 (LWT)**：利用 MQTT 原生特性，在异常断线时由 Broker 自动广播 `leave` 消息。
- **在线人数重复计算**：修复 `presence` 消息广播导致自己被重复计入在线列表的问题，统一在渲染和计算前过滤掉自己。
- **文件/语音消息去重失效**：统一本地消息 ID 与 MQTT 发布 ID，为语音消息补充标准 `id` 字段，防止 Broker Echo 导致重复消息。
- **日志面板滚动跳动**：修复移动端打开日志面板时页面闪烁的问题，增加平滑滚动及面板打开状态判断。

### 性能与资源 (Performance & Resources)
- **ObjectURL 内存泄漏**：修复发送/接收图片、文件、语音时创建的 `URL.createObjectURL` 从未释放的问题，统一在组件卸载或断开连接时调用 `revokeObjectURL`。
- **AudioContext 资源泄漏与挂起**：修复移动端首次加载时音频上下文 `suspended` 导致无声的问题；修复组件卸载后延时 beep 报错的问题；在组件卸载时正确调用 `ctx.close()` 释放资源。
- **MusicPlayer 双重初始化**：修复 React StrictMode 下 APlayer 实例绑定到已卸载 DOM 节点导致白屏的问题。
- **CSS 死代码清理**：清理 `index.css` 中残留的 `.emoji-panel` 等废弃样式。
