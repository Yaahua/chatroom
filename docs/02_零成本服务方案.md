# GitHub Pages 纯静态架构下的零成本进阶方案

在 GitHub Pages 等纯静态托管平台的约束下，前端代码无法运行任何服务端逻辑（如 Node.js 或数据库）。然而，通过巧妙地拼接各种提供免费额度的云服务（Serverless/BaaS），我们完全可以构建出一个功能丰富且无需自己维护服务器的现代化 P2P 聊天室。

本方案专为国内开发者设计，在兼顾国内访问速度的前提下，实现**信令服务器**、**TURN 穿透**、**持久化存储**的零成本替代。

## 1. 信令服务器：Serverless WebSocket 方案

原项目硬编码了公共 MQTT 服务器，这存在极大的安全隐患和稳定性问题。在静态托管环境下，我们需要第三方实时通信服务来交换 WebRTC 的 SDP 和 Candidate 信息。

### 推荐方案一：EMQX Cloud Serverless（国内访问最佳）

EMQX Cloud Serverless 提供了无需部署的云端 MQTT 代理，特别适合作为信令服务器使用 [1]。

*   **免费额度**：每月 100 万连接分钟，1 GB 流量，100 万规则动作数。对于个人或小团队的聊天室测试完全足够 [1]。
*   **国内优势**：提供国内可用节点，延迟低，连接稳定性远高于海外的免费服务。
*   **实现方式**：前端直接引入 `mqtt.js`，通过 WSS（WebSocket Secure）协议连接到 EMQX 分配的专属接入点。可以使用用户名/密码进行基础鉴权，每个房间分配不同的 Topic（如 `chatroom/room_id/signaling`）。

### 推荐方案二：Supabase Realtime（功能最全）

Supabase 是一个开源的 Firebase 替代品，其 Realtime 模块支持基于 WebSocket 的状态同步和广播 [2]。

*   **免费额度**：每月 200 万次实时消息广播，同时支持 50,000 个月活跃用户和 500 MB 数据库存储 [3]。
*   **国内优势**：虽然服务器在海外，但亚太节点（如新加坡）在国内的访问速度尚可接受。
*   **实现方式**：使用 `@supabase/supabase-js`，利用其 Broadcast 功能实现房间内的 SDP 交换，甚至可以使用 Presence 功能轻松实现"在线用户列表"和"正在输入"状态。

## 2. NAT 穿透：免费 TURN 服务器替代

WebRTC 在复杂的网络环境（如对称 NAT 或企业防火墙）下，必须依赖 TURN 服务器进行流量中继。自建 Coturn 需要服务器成本，我们可以利用免费的第三方服务。

### 推荐方案：Metered Video OpenRelay

Metered 提供了一个名为 OpenRelay 的免费 TURN 服务器服务，专门为 WebRTC 开发者设计 [4]。

*   **免费额度**：每月提供 500 MB 的免费 TURN 中继流量，STUN 请求无限制 [5]。由于我们的媒体传输主要依赖 P2P（只有穿透失败时才走 TURN），且信令已由 EMQX/Supabase 解决，500 MB 流量对于纯文本和低频语音的聊天室已足够初期使用。
*   **国内优势**：全球 31+ 个区域部署，包含亚太节点，国内可用。
*   **实现方式**：在前端的 `RTCPeerConnection` 配置中，填入 Metered 提供的专属 STUN/TURN 地址和凭证即可。

## 3. 持久化与文件存储：BaaS 拼接

原项目是阅后即焚的，且文件传输依赖 P2P。如果需要增加离线消息、历史记录或大文件分享功能，需要外部存储。

### 数据库替代：腾讯云 CloudBase 或 Supabase

*   **腾讯云 CloudBase（云开发）**：新用户提供 30 天免费试用（含 8 GB 数据库和 50 GB 存储），之后基础套餐低至 9.9 元/月 [6]。这是国内访问速度最快、合规性最好的方案。
*   **Supabase Postgres**：如果选择了 Supabase 作为信令，可以直接复用其免费的 500 MB Postgres 数据库存储历史消息。

### 文件存储替代：GitHub Issues / Cloudflare R2

*   **极客方案（零成本图床）**：利用 GitHub API，将用户发送的图片转为 Base64 后，通过 API 创建一个不可见的 GitHub Issue 评论，从而获取 `user-images.githubusercontent.com` 的直链。
*   **正规方案（Cloudflare R2）**：Cloudflare 的对象存储 R2 提供每月 10 GB 的免费存储空间和数百万次的免费读写操作，且免收出站流量费 [7]。前端可以通过预签名 URL（需借助 Cloudflare Workers）直接上传文件。

## 4. 静态托管加速：腾讯云 EdgeOne Pages

虽然项目托管在 GitHub Pages，但国内直接访问 `github.io` 域名往往存在 DNS 污染或极高延迟。

*   **优化方案**：使用腾讯云新推出的 **EdgeOne Pages** 免费版 [8]。
*   **优势**：将 GitHub 仓库授权给 EdgeOne Pages，它可以自动拉取代码并部署在腾讯云的全球边缘节点上。免费版提供无限量的静态加速流量和基础的 DDoS 防护，能让国内用户的首屏加载速度从数秒缩短至毫秒级。

## 总结：推荐的零成本技术栈组合

| 模块 | 推荐服务 | 免费额度 / 成本 | 国内可用性 |
| :--- | :--- | :--- | :--- |
| **前端托管** | GitHub Pages + EdgeOne Pages | 免费，无限量流量 | 极佳（边缘节点加速） |
| **信令服务器** | EMQX Cloud Serverless | 100 万连接分钟/月，1GB 流量 | 极佳（国内节点） |
| **TURN 穿透** | Metered OpenRelay | 500 MB 中继流量/月，无限 STUN | 良好（亚太节点） |
| **实时状态/广播** | Supabase Realtime | 200 万条消息/月 | 良好（新加坡节点） |

通过上述云服务的拼接，你可以完全抛弃传统的服务器购买与运维流程，在 GitHub Pages 上实现一个具备企业级实时通信能力的 P2P 聊天室。
